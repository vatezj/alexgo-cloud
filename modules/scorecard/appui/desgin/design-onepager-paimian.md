# 「牌面」— Creative Concept One-Pager

> 打牌记账 App 重设计推荐方向详案 · 2026-10-09 · 配套提案见 [design-proposal.md](design-proposal.md)

## Insight

朋友们想把输赢得失看得清清楚楚，但没人想当那个斤斤计较的人——因为嘴上说"就是玩玩"，账上的数字却是真金白银的真心。

## Idea

分数住在牌里，账目冷得像裁判，牌面可爱得像朋友。UI 构件全部来自牌/筹码世界（Closed World），账目排版保持铅字级冷峻——**玩味负责留面子，冷排负责绝对公正**。

## Tagline

> **输赢有数，面子周全。**

（次级文案钩子：`给个牌面` / `这局，牌面上见` / `牌面上两清了`）

## Key Visual / Hero Execution（前 3 秒）

记分页：炭墨桌面上摊着 4 张**骨白大牌**（每位玩家一张，牌背有细编织纹），牌面中央是铅字冷排的 `+120`——朱红、带着一枚若隐若现的红中印；两侧各一枚筹码造型的 `＋/−` 钮。点下 `＋`，一枚 `+20` 金色筹码气泡从分数上方浮起、上移淡出，分数染上朱红微光。

## Visual World（Token 草案）

### 配色

| Token | Hex | 用途 |
|---|---|---|
| `ink/900` | `#14120F` | 页面炭墨底（牌桌夜色） |
| `ink/700` | `#1E1B17` | 深色面板/TabBar |
| `ink/600` | `#2A2722` | 按压态、分隔 |
| `tile/100` | `#F2EDE3` | 骨白牌面（玩家卡/主 CTA 底） |
| `tile/阴影` | `rgba(0,0,0,.45)` | 牌的厚度投影（双层：贴地+悬浮） |
| `vermillion/500` | `#D23B22` | 漆红——赢/正分（牌面白底上的金替代色，对比度达标） |
| `indigo/500` | `#3D5A96` | 靛蓝——输/负分 |
| `jet/500` | `#2A2722` | 墨——中性/0（在牌面上） |
| `brass/500` | `#C9A24B` | 黄铜——深底上的强调、赢家牌描边、hero 数字 |
| `jade/500` | `#3E7D5A` | 翠——第二辅助（底分、进行中标记） |
| `text/on-ink` | `#EDE6D8` | 深底主文字 |
| `text/dim` | `#9B917F` | 深底辅助文字 |

**花色分派（玩法 = 花色）**：麻将 = 漆红 · 斗地主 = 靛蓝 · 掼蛋 = 翠 · 德州 = 黄铜。
玩法 chip、战绩分屉、开局选择全部按花色着色——一套颜色同时编码"游戏类型"。

**金额用色规则（不可变）**：白底牌面：赢 = 漆红 / 输 = 靛蓝 / 平 = 墨；深底 hero：赢 = 黄铜 / 输 = 靛蓝。
**每个金额必带 +/−/0 符号**（防色弱，符号是信息、颜色是增强）。

### 字体

| 角色 | 字体 | 说明 |
|---|---|---|
| 金额/分数 | **Oswald** SemiBold/Bold | 铅字冷排，等宽数字，加分不跳动 |
| 中文标题 | **Noto Serif SC** Bold（待验证可用性） | 招牌/账本气质，字距 +2%；不可用则退回 Noto Sans SC Black + 字距 |
| 中文正文 | **Noto Sans SC** Regular/Medium | 中性衬托 |

字号阶梯沿用 v1 的 9 级（72/48/32/24/18 → 26/18/15/13/11），只换字体气质，不换节奏。

### 圆角 / 材质 / 效果

- `radius/tile = 12`（牌边，新增）· `radius/md = 14` · `radius/lg = 20` · `full`（筹码钮）
- **牌厚投影**：`0 2px 0 rgba(0,0,0,.5)`（贴地厚度）+ `0 10px 24px rgba(0,0,0,.45)`（悬浮）——牌是实体，不是纸片
- **牌背纹**：45° 细编织/网格纹，opacity ≤ 6%，只出现在卡头条与续局卡，绝不进入分数区
- **红中印**：赢家卡右下角 24px 朱红篆印（本局 M 标记），静态水印级存在感
- 效果样式：`shadow/tile`（上述双层投影）、`glow/brass`（深底 hero 微光）

### 动效

1. 加分：筹码气泡 `+N` 上移 12px / 400ms 淡出（沿用已确认规范）
2. 按钮：筹码按压下沉 2px + 内阴影（80ms）
3. **开牌**（结算页签名动效）：结算卡从牌背翻转 180° 露出金额，300ms ease-out，依次错峰 60ms
4. **盖章**（保存战绩）：红中印从 1.4× 缩落 + 轻微旋转，180ms，触感回馈
5. 撤销：上一张"牌"沿弧线收回牌堆，250ms

## 5 页逐屏详案

### ① 首页 —「牌桌上，还有半局」

- 顶部：牌匾式标题「牌局账本」（Serif + 黄铜发丝线），副题 caption
- **续局卡（本页主角）**：一张摊开的骨白大牌，黄铜描边 = 进行中；内容：玩法花色条 +「老王家的麻将局 · 第 6 局」+ 我的成绩小字（带符号）；整卡可点 → 记分页
- 最近牌局：横排 3 张小牌（牌谱），每张 = 日期 + 玩法花色点 + 带符号金额
- 拇指区：`＋ 新开局` 黄铜胶囊 CTA（FILL）+ 深色 TabBar（首页 active 黄铜）
- 空状态：一张扣着的牌 +「喊一声，开一局」

### ② 开局设置 —「翻牌开局」

- 玩法选择 = **4 张扣着的牌**，点选即翻面：牌面显示玩法名 + 花色色块（麻将默认翻开=漆红）
- 玩家 = 筹码头像（叠放 2-3 枚的筹码塔造型），「＋加一位」= 虚线筹码
- 底分 = BaseScoreControl 沿用，值改黄铜色，两侧筹码钮
- 拇指区：`开始牌局` 骨白胶囊（tile 底 + 墨字，与首页黄铜 CTA 区分层级：首页=回牌桌，开局=落子）+ caption 复核行「4 人 · 麻将 · 底分 ¥10」

### ③ 记分页（核心）—「牌面上见」

- 顶栏：`麻将 · 第 6 局`（Serif）+ 底分控件
- 4 张骨白玩家牌竖排（350 宽，牌厚投影）：
  - 牌头条（16px，牌背纹 + 玩法花色条）：头像筹码 + 名字 + `第 6 局`
  - 分数区（留白 ≥ 24px，**无任何纹理**）：Oswald 48pt 冷排，带符号，按状态染 漆红/靛蓝/墨
  - 操作区：左 `−` 右 `＋` 筹码钮（56px，＋黄铜底墨字 / −靛蓝底白字；Pressed = 下沉 2px）
  - 赢家牌：黄铜 2px 描边 + 右下红中印
- 动效叠加：`+N` 筹码气泡（黄铜底）从分数上方浮出；分数色染 + 微光 300ms 回落
- 拇指区：`[撤销]`（描边）`[结束牌局]`（黄铜实心）横排，底分快照在撤销旁
- 画布旁标注：动效时序说明卡（沿用 v1 的标注做法）

### ④ 结算 —「开牌，两清」

- Hero：「我的净成绩」+ 72pt 黄铜大数（深底），副题 `6 局 · 底分 ¥10`
- 4 张结算卡 = **牌背朝上的牌**，载入时自上而下错峰**翻牌**：翻面后左信息（名字 Serif + 净赢/净输 caption）右金额（32pt，带符号，花色色）
- 赢家行：黄铜描边 + 红中印；总和守恒校验行（小字）：`+360 −80 −160 −120 = 0`
- 拇指区：`编辑明细`（描边）→ `保存战绩`（黄铜）；点保存触发**盖章动效**，toast「已记入人情牌谱」→ 返回首页

### ⑤ 战绩 —「牌谱」

- Hero：牌匾式累计值（黄铜 72pt）+ `32 局 · 胜率 56%`
- **按玩法分屉**：4 个花色抽屉（麻将红/斗地主蓝/掼蛋翠/德州铜），行内条形图 = **筹码堆叠条**（圆形筹码横排替代实心条，宽度=金额比例，负值用靛蓝筹码）
- 最近牌局：牌谱行（日期 + 花色点 + 带符号金额），行 hover/按压 = 牌抬起 1px
- TabBar 战绩 active 黄铜
- 空状态：空牌架 +「牌谱还空着，开一局就记上」

## 3 Executions（签名组件）

1. **玩家牌（PlayerTile）**：骨白牌 + 牌头条纹理 + 铅字分数区 + 筹码操作区——全 App 出现频率最高的形态，牌厚投影是它的身份证
2. **开牌结算（Flip Settlement）**：牌背→翻面→金额+红中印，把"看账"变成"开奖"的仪式
3. **筹码钮（Chip Button）**：＋黄铜 / −靛蓝，按下即沉——1 秒记分的手感来源

## How It Lives（延伸）

- 分享战绩 → 生成"牌谱卡片"图（牌面造型，天然适合发微信群）
- 多局历史 → 牌谱册（按晚分页）
- 未来扩展：花色系统直接容纳新玩法（新玩法 = 新花色，零改色板）

## Evaluation

- 加权总分 **8.35** / HumanKind **8** / Grey **8**（详见提案）
- 强项：张力两端同时成立、Simplicity 9（"账就是牌，牌就是面"）
- 弱项：Feasibility 7.5——牌纹小屏降噪、Noto Serif SC 可用性、牌厚投影在低端机的层渲染，需 3 屏视觉稿验证

## 风险与开放问题

1. 牌背纹是否在 4 卡堆叠时产生摩尔纹 → 纹理限卡头 16px 条带，分数区绝对无纹
2. 漆红 `#D23B22` 在骨白上的对比度 ≈ 4.7:1（大字号达标，小字 caption 需加深至 `#B32D18`）
3. Serif 中文标题若字库缺失 → 回退方案：Noto Sans SC Black + 字距 +2%，气质靠黄铜发丝线补
4. 需用户测试的问题（决定能否上 9 分）：**"牌面"会不会太花而干扰 1 秒记分？

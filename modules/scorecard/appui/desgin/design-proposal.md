# CREATIVE BRIEF RESPONSE — 打牌记账 5 页重设计提案

> 产出方式：creative-director skill 全流程（INTAKE → INSIGHT → IDEATION → EVALUATE → ARTICULATE）
> 日期：2026-10-09 · idea level: `brand`（全产品视觉平台）· 只出设计，不写码

## Brief（一段）

打牌记账：朋友局（麻将/斗地主/掼蛋/德州）的轻量记分结算 App，移动端 390×844，5 个页面（首页/开局/记分/结算/战绩）**全部重新设计**。用户是牌局里那个默默记账的人；硬约束：1 秒记分、拇指热区、金额必带 +/−（防色弱）。v1（桌布墨绿+暖金）已存在，本次要**不同方向**。

## Insight

> **朋友们想把输赢得失看得清清楚楚，但没人想当那个斤斤计较的人——因为嘴上说"就是玩玩"，账上的数字却是真金白银的真心。**

## Tension（类别张力）

记账类产品全在模仿财务软件的**严肃克制**；而牌局是全中国最松弛、也对钱最敏感的社交现场。严肃→伤感情，嬉皮→不可信。**好的设计要同时握住两端。**

## IDEA #1: 「牌面」— 输赢有数，面子周全 — ★ 推荐

**Concept**：分数住在牌里，账目冷得像裁判，牌面可爱得像朋友——UI 的一切构件（卡片、按钮、数字底衬）都是牌/筹码的抽象形，而账目行本身是铅字般冷峻的排版。

**一句话**：`牌面` = 中文双关——既是牌的正面，更是"给个牌面"的面子。记账 App 给全桌人留面子。

**可视化（记分页示意）**：

```
┌──────────────────────────┐
│ 麻将·第6局      [底分 ¥10]│
│ ┌──────────────────────┐ │
│ │ 🀄 王 老王     第6局  │ │
│ │  [−]   +120   [＋]   │ │  卡片=牌背纹样底衬
│ └──────────────────────┘ │  分数=铅字冷排 Oswald
│ ┌──────────────────────┐ │  ±  = 筹码圆钮
│ │ 🀄 我        第6局   │ │
│ │  [−]   −40   [＋]    │ │
│ └──────────────────────┘ │
│  [撤销]        [结束牌局] │
└──────────────────────────┘
```

**5 页落位**：
- **首页**：续局卡 = 一张摊开的牌；战绩列表 = 牌谱
- **开局**：玩法选择 = 四张扣着的牌翻开；玩家头像 = 筹码
- **记分**：牌背纹理卡 + 冷峻账目行 + 筹码 ± 钮
- **结算**：每人一张"牌面"翻开，金额像开牌一样甩出；赢家牌描金边
- **战绩**：累计值压在"王牌"大图形上；按玩法分组 = 按牌种分屉

**配色**：炭墨底 + 骨白牌面 + 朱红/靛蓝花色；赢金输蓝规则不变。
**字体**：数字 Oswald 冷排 + 标题中文带招牌/账本气质（区别于 v1 的 Noto 中性）。

**Rationale**：同时握住两端——牌面玩味化解"斤斤计较"，账目冷排保住"绝对公正"（张力不解决，正是它成立的原因）。
**饱和度校准**：P11（荒诞作载体）广告库 50+ 案例、常规上限 7；此处非常规翻新，而是把荒诞升级为**整套 UI 系统**（结构性新变体），故放行 8.5。
**血统**：VW Fun Theory（让正确行为变好玩——记账变成游戏的一部分）+ Clash of Clans Revenge（对尴尬情绪正面直给）。

## IDEA #2: 「记分台」— 牌桌官方，数字作证

**Concept**：把记账员从"最讨人嫌的人"升格为"官方记分台"——UI 是一块深夜赛场的电子记分牌，数字是 LED 点阵琥珀光，权威、中立、不站队。

**5 页落位**：首页 = 今晚赛程板；开局 = 球队入场名单；记分 = 主记分牌（超大点阵数字）；结算 = 赛后成绩公告 + 印章；战绩 = 赛季积分榜（排名、升降箭头）。

**配色**：炭黑机箱 + 琥珀 LED + 绿点阵辅助；点阵/等宽数字质感。

| 加权总分 | HumanKind | Grey |
|---|---|---|
| **8.25** | 8 | 8 |

**Rationale**：对 Insight 的解法最直接——"公正的第三方机构"让数字不带私人情绪（SF 9.0 最高）。弱点：Emotional 仅 Tier 2；"近黑底+单亮色"是 AI 生成设计高频雷区，必须靠点阵纹理、机箱质感、双色 LED 拉开。
**血统**：Budweiser Whassup（放大已存在的仪式——牌局本就互称"裁判"）+ PlayStation Double Life（给不被承认的生活以尊严——给记账员以尊严）。

## IDEA #3: 「人情簿」— 记的是账，留的是情

**Concept**：农村记礼金的簿子、老会计的红格账本——把结算重构成"人情往来"：输赢不是亏损，是这局交情的注脚。纸面、红格线、朱砂印章、账房手写数字。

**5 页落位**：首页 = 簿子封面（最近一页）；开局 = 登记拜帖；记分 = 红格账页逐行记；结算 = 盖章画押"此局两清"；战绩 = 翻旧账，每页是一晚。

**配色**：账簿纸 + 墨黑 + 朱红格线与印章；数字手写体感（需中文字库验证）。

| 加权总分 | HumanKind | Grey |
|---|---|---|
| **7.53** | 7.5 | 7 |

**Rationale**：情感最深（Tier 3 bittersweet belonging），"把钱重构成情"直接消解张力。失分在 Originality——米色纸+衬线是生成式设计头号套路区，必须用**红格账簿结构**出圈；浅色底与深夜牌局有温差；手写中文字库制约 Feasibility。
**血统**：Spanish Lottery Justino（奖品不是重点，你和谁一起才是）。

## DISCARDED DIRECTIONS

- **夜局霓虹（港式麻将馆）**：霓虹描边中文渲染成本高、视觉噪音冲突"金额是绝对主角"；霓虹美学在餐饮 App 已饱和。
- **德州 HUD 数据风**：换任何竞技 App 都成立——Specificity Test 不过，originality ≤ 5。
- **黑白极简账单（SIT 减法）**：结构漂亮但零情绪，落入"白底+衬线"AI 套路。

## RECOMMENDATION

**开发「牌面」**。唯一同时满足张力两端的方向（公正×不伤面子），有字面双钩子（牌面=面子）可贯穿文案系统，五页落位全部自然，对 v1 是真换代而非换色。
下一步：定 3 张关键屏（记分/结算/战绩）高保真视觉稿 → 验证牌纹在小屏的降噪表现 → 额度恢复后入 Figma。

## PROCESS

- **方法**：SIT（减法/任务统一/图形类比）× Bisociation（麻将馆/人情簿碰撞）× Provocation PO（"记分牌"、"牌面即 UI"），3 类各一
- **案例校准**：7 张卡（Double Life / Champagne / CoC Revenge / Whassup / Justino / Fun Theory / Small World Machines）
- **递归**：2 轮改进 + 1 轮模式饱和度校准
- **停止原因**：平台期（连续 2 轮 delta < 0.3，顶在 8.35）。诚实说明：9+ 需真实用户对"牌面是否太花"做可用性测试才能给，提案阶段按 8.x 交付。

# Figma 进场计划 — 哪套方案、怎么进、花多少额度

> 2026-10-09 决策文档 · 约束：Starter + View 席位 = **20 次 MCP 调用/月**（2026-10 额度已耗尽）

## 决策：哪套方案进 Figma？

| | 方案 A：v1 墨绿+暖金 | 方案 B：牌面（推荐） |
|---|---|---|
| 成熟度 | token/样式/6 组组件/首页已落地，4 屏脚本备好 | 详案+HIG 审查+HTML 视觉稿完成，未进 Figma |
| 设计方向 | 已确认过的稳妥方案 | creative-director 评分 8.35，赢得本次重设计 |
| 进场成本 | ~8 次调用（脚本即贴即用） | ~10–12 次调用（需新建 token/组件） |

**结论：牌面（方案 B）进场；v1 文件原样封存为档案与回退方案。**

理由：用户本轮的明确目标是"全部 5 页重新设计"，牌面是评审后的推荐方向；v1 已有完整落地方案，随时可退回，不浪费任何已有工作。

## 怎么进：新建文件（绕开 3 页限制）

1. **`create_new_file` 新建文件**「牌面 · 打牌记账 v2」——该工具**在豁免名单内，不消耗 20 次额度**

3. 旧文件 `dHMgzmrrWJ8ztjWytPXdIW` 不做任何写入，永久保留 v1

**硬性执行纪律**（来自本月教训）：
- 结构容器一律 `fills = []`（createAutoLayout 默认白底）
- `appendChild()` 不可链式取返回值
- 每脚本只切一次页面；绝不并行调用 use_figma
- 先贴 `hig-review.md` 的两处必改（vermillion/600 小字红、底部 34pt 安全区）再画屏
- 字体先 `listAvailableFontsAsync` 验证 **Noto Serif SC** 是否可用（回退：Noto Sans SC Black + 字距）

操作说明 · 细微技巧 · 隐藏功能 · 反馈解决
♥01
重要提示
  • “打牌记账”是记账、计分工具 — 不能涉及金钱，禁止用于违法行为
  • 需要帮助：微信客服留言（人多请耐心等待，24h 内回复）
  • 网络：保持网络良好、亮屏体验最佳（息屏会断小程序网络）；数据不实时下拉刷新，或右上角三点 → 重新进入小程序
♠02
结算 · 退房 · 历史记录
  • 结算：仅提供策略参考，可不按策略，均线下自行处理
  • 退房：只能自己退房，没有踢人；结算后点头像退出，数据为零可直接退；房间无操作 2 小时自动关闭
  • 战绩：首页点战绩 → 房间记录，左滑有流水 / 排行 / 删除；好友排名内页左滑可删除、拉黑，点图标可清零
♦03
茶饭设置完成
  • 房间点茶/饭弹层配置：目标金额 + 抽取百分比；目标金额 > 0 则开关开启
  • 方式一：抽取百分比 > 0% 时，每次支出记账，赢方按比例另行记为茶饭
  • 方式二：房间左下角支出按钮，直接 DIY 数值记为茶饭
♣04
房间语音
  • 语音分三类：娱乐 / 流水 / 房间动态；点头像弹窗右侧喇叭，5 档循环：全部关闭 → 全部播放 → 娱乐关闭 → 流水关闭 → 操作播放
  • 默认：操作播放（人员进出、结算）；开房人默认全开
♠05
好友排名完成
  • 内页左滑：删除好友、拉黑好友；可切换「不参与排名 / 加入排名」
♥06
添加广告说明
  • 非收费工具，服务器成本高，增加广告投放带来体验损失敬请谅解；广告位尽量避开功能按钮，减少误入
♦07
功能优化
  • 部分机型房间信息/广播停止更新：与 WiFi 长连接被断有关，建议 4G；房间支持下滑刷新、检查网络；锁屏久后进入会提示确认刷新
♣08
需求反馈开发中
  • 战绩自定义统计：增加统计入口，可按月份 / 年份 / 具体记录统计

# fun-salary Delta Spec

## MODIFIED Requirements

### Requirement: 算薪口径

指标 SHALL 按锁定口径计算：每月计薪天数固定 **21.75 天**（法定月计薪天数，页面标注，恒定不随月变）；每日工时 = 上午(下班−上班) + 下午(下班−上班)（分钟差，非正数视为无效并保持上次有效值）；日薪 = 月薪 / 21.75；时薪 = 日薪 / 每日工时；每秒 = 时薪 / 3600。**今天入账** = 今日**工作日**已过班次秒数 × 每秒；**本月入账** = 本月已过完整**工作日**（不含今日）× 日薪 + 今日已入账。**工作日判定 SHALL 认法定节假日与调休**：法定假日（如国庆）当日即使周一至周五也 SHALL NOT 计为工作日；调休补班日（周末上班）SHALL 计为工作日；假日数据缺失或加载失败 SHALL 退化为周一至周五判定且不阻塞计算。结果保留 2 位小数。

#### Scenario: 锁定快照自洽
- **WHEN** 输入 15000 / 09:00–12:00 / 13:30–18:00（非节假日）
- **THEN** 每日工时 7.5h、日薪 ¥689.66、时薪 ¥91.95、每秒 ¥0.0255（与设计稿一致）

#### Scenario: 法定假日不入账
- **WHEN** 今天是国庆假期内的周一至周五（假日表标记 `isOffDay:true`）且处于原上班时段
- **THEN** 今日入账 ¥0.00、今日工作时间 0:00:00 起跳；hero 仍显示但金额不涨

#### Scenario: 调休补班照常入账
- **WHEN** 今天是调休补班的周六（假日表标记 `isOffDay:false`）且处于原上班时段
- **THEN** 按工作日正常计算今日已工作秒数与今日入账

#### Scenario: 假日数据缺失退化
- **WHEN** 本地打包与远程 JSON 均不可用（断网/404/格式非法）
- **THEN** 按周一至周五判定继续渲染，页面不报错、不白屏；下次进入页面可重试

#### Scenario: 非法时段
- **WHEN** 选择的下午下班时间早于下午上班时间
- **THEN** 该组工时不计入（或保持上次有效工时），页面不出现 NaN/Infinity

### Requirement: 当月工作日展示

页面「本月入账」卡片副标题 SHALL 展示**当月实际工作日总数**与进度（「本月 X 个工作日 · 第 N 个」），X 随月份与节假日变化（如 2 月少、10 月含国庆调整）；假日数据未就绪时 SHALL 回退现文案（「本月第 N 个工作日计」）。SHALL NOT 改动「每月工作日 21.75 天」格子的值与「法定月计薪天数」标注。

#### Scenario: X 随月变化
- **WHEN** 假日表已加载，分别在 2 月与 10 月查看
- **THEN** 副标题的 X 为各月实际工作日数（含调休修正），两月数值不同

#### Scenario: 21.75 格子不动
- **WHEN** 任意月份查看明细区「每月工作日」格
- **THEN** 值恒为 21.75 天、标注「法定月计薪天数」

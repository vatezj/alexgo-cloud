# Spec Delta: auth/auto-login

## Purpose

小程序端免点击自动登录：冷启动无登录态时静默恢复微信会话，凡落到登录页也自动完成登录，用户无需手动点击登录按钮；失败时回退到既有手动登录路径。

## ADDED Requirements

### Requirement: 冷启动静默登录（仅微信小程序端）

微信小程序端冷启动时若本地无有效登录态，系统 SHALL 静默执行微信 code 登录（不展示登录页、不需要用户点击）；登录成功后 SHALL 写入登录态并可正常请求需登录接口。H5 端 SHALL 不执行静默登录，行为与现状一致。

#### Scenario: 冷启动无 token 静默登录成功

- **WHEN** 微信小程序冷启动，本地无 token，静默 code 登录成功
- **THEN** 登录态写入持久化存储，用户直接停留在启动页流程（首页），全程不出现登录页

#### Scenario: 冷启动静默登录失败

- **WHEN** 微信小程序冷启动，本地无 token，静默登录失败（网络错误 / 微信接口失败 / 后端拒绝）
- **THEN** 应用保持未登录态启动（不崩溃、不循环重试），用户经既有入口进入登录页时仍可手动登录

#### Scenario: 冷启动已有 token 不触发静默登录

- **WHEN** 微信小程序冷启动，本地已有 token
- **THEN** 不发起静默登录请求，沿用既有 token 恢复流程

#### Scenario: H5 不受影响

- **WHEN** H5 端冷启动
- **THEN** 不执行任何静默登录，登录页仍为手机号密码手动表单

### Requirement: 登录页自动触发登录（仅微信小程序端）

微信小程序端进入登录页且无登录态时，系统 SHALL 自动触发微信登录，无需用户点击；成功后 SHALL 走与手动点击「微信一键登录」完全相同的登录成功收口（持久化 token、拉取资料、scene 绑好友/进房或回首页）。

#### Scenario: 被动进入登录页自动登录成功

- **WHEN** 小程序端因未登录（如 401 清态、首页点开房/进房）进入登录页，且无 scene 进房意图
- **THEN** 系统自动完成微信登录并跳转首页，用户未点击任何按钮

#### Scenario: 带 scene 进房意图自动登录后进房

- **WHEN** 小程序端因 scene 进房（扫码/卡片）未登录进入登录页，暂存 scene 中有房号
- **THEN** 自动登录成功后与手动登录一致：静默绑好友、进对应房间，只进一次、不回环消费 scene

#### Scenario: 登录页自动触发失败回退手动

- **WHEN** 小程序端登录页自动触发的微信登录失败
- **THEN** 登录页展示手动登录按钮（微信一键登录 / 手机号登录），用户可点击重试；自动触发不无限循环

#### Scenario: 并发触发去重

- **WHEN** 自动登录在途时用户又手动点击登录按钮（或另一入口再次触发自动登录）
- **THEN** 不重复发起登录请求，后到的触发复用同一在途结果或被忽略，不产生双请求/双跳转

### Requirement: 已有登录态进入登录页即离开

用户已登录（本地有 token）时进入登录页，系统 SHALL 立即离开登录页返回可用流程（首页），不停留、不再发起登录请求。

#### Scenario: 已登录误入登录页

- **WHEN** 已登录用户因路由残留或手动导航进入登录页
- **THEN** 登录页立即跳转首页，不展示登录表单、不发起新登录

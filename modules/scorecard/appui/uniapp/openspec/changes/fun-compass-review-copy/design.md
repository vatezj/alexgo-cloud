# Design: fun-compass-review-copy

## Context

- 审核风险集中在两类：① 前端可见的「八字/排盘/生辰/五行」；② 后端 reason 原文（奇门生门、财气、吉凶、煞星…）经 `zhiwei.ts` → 结果卡直出。
- `copy.ts` 头注释称免责为 PRD 逐字锁定——上架合规优先于 PRD 锁定，本轮改 copy 并在任务里注明 PRD/设计稿需回写。
- 评分逻辑与 API 字段契约不动，只动字符串，降低回归面。

## Decisions

### D1 术语替换表（前端）

| 原 | 新 |
|----|----|
| 排八字 · 看推荐 | 测个方位 · 看推荐 |
| 排八字 · 求个座 | 试试方位 · 求个座 |
| 排八字，求个座 | 测个方位，求个座 |
| 排八字 · 看罗盘 · 求个座 | 测方位 · 看罗盘 · 求个座 |
| 排盘中… | 计算中… |
| 排盘失败 / 排盘请求失败 / 排盘服务… | 测算失败 / 测算请求失败 / 测算服务… |
| 生辰排盘（nav） | 趣味方位 |
| 生辰档案（nav/卡名） | 出生档案 |
| 填生辰，排个盘/座 | 填出生时间，测个方位/座 |
| 生辰（表单 label/picker title） | 出生时间 |
| 选择生辰 | 选择出生时间 |
| 生辰选择有误 | 出生时间选择有误 |
| 从生辰档案选择 | 从出生档案选择 |
| 本地生辰，算五行 | 本地出生时间，测方位 |
| 生辰 · 罗盘 · 选座小彩蛋 | 出生时间 · 罗盘 · 选座小彩蛋 |
| 填一份生辰就能排盘求座 | 填出生时间就能测方位求座 |
| 先去排盘页存一份 | 先去测算页存一份 |
| 排盘即算即走 | 测算即算即走 |
| 生辰信息/生辰档案（about/clear） | 出生信息/出生档案 |
| 五行方位结论（about 第2段） | 方位参考结论 |
| 排盘计算经后端… | 方位测算经后端… |
| 东=木 南=火 西=金 北=水（罗盘条+说明） | 东向 · 南向 · 西向 · 北向 |

保留：趣味方位、罗盘、选座、民俗趣味、两句免责主干、「本次无显著方位信号，随缘落座」。

### D2 后端 reason（仅字符串）

| 触发 | 原 reason | 新 reason |
|------|-----------|-----------|
| 生门 +50 | 奇门生门落此方，主生机与财气 | 传统方位模型在此向给出正向评分 |
| 旺衰 >0 | 生门在X旺相 | 该向综合权重上调 |
| 旺衰 <0 | 生门在X衰囚 | 该向综合权重下调 |
| 吉星≥2 | 紫微X吉星聚集（…） | 辅助因子聚集，得分上调 |
| 煞星≥2 | X煞星较多（…），建议避开 | 辅助因子不利，得分下调，建议优先其他向 |
| 无理由 | 无显著吉凶信号 | 无显著方位信号 |

`score` 数值、`+50/+25/-15/旺衰权重`、top3、`score>0` 过滤一律不动。

### D3 黑名单

`copy.ts` 的 `FORBIDDEN_WORDS` 保持既有涉钱词（PRD §7）；另导出 `REVIEW_RISK_WORDS`（八字、排盘、运势、吉凶、算命、占卜、财气、煞星、旺相、紫微、奇门、生门、命宫…）供任务 grep 自测。用户可见模板与 copy 常量 0 增中（注释/代码标识符除外）。

### D4 测试

`scoring.test.js` 断言 reason 的正则改为 D2 新文案；分值断言一字不改。`npm test` 37 项全绿。

## Risks / Out of Scope

- 不改：路由名 `bazi.vue`、API 字段、档案 storage schema、分享卡默认、PRD/desgin 图稿（另开文档回写）。
- 微信审核仍可能对「生辰/出生时间+性别」采集敏感——已有「仅本机、即算即走」隐私句，本轮不扩采集面。

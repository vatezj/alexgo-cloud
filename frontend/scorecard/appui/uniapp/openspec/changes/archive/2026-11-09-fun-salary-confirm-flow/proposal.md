# Proposal: fun-salary-confirm-flow

## Why

用户 2026-11-09 对 `pages/fun/salary/index` 的交互反馈：未填写工资与上班时间时，下方结果区不应展示；填写后表单折叠为一行摘要（带向下箭头可再展开）；输入区需要确认按钮。当前实现是「选值即算、结果常显」，缺少明确的确认步骤与空态。

**同日修订轮（用户三点补充）**：① 小程序窄屏右边显示不全（布局溢出 bug）；② 月薪要「既能选择也能输入」；③ 上班时间给默认值（月薪也给默认 15000）。

## What Changes

- **布局修复**：`.fcn-nav/.sal-content/.sal-footer` 共享宽度规则补 `box-sizing: border-box`——content-box 下 `width:100%` 不含水平 padding，窄屏（390px/小程序）总宽溢出右边。
- **月薪双通道**：数字**输入框**（直接键入）+ 右侧「**选**」按钮开原有轮选（3000–100000 步 500），轮选确认回填输入框；月薪默认 **15000**。
- **时间默认值**：四时间点仍走轮选，带默认 `09:00–12:00 / 13:30–18:00`（不再空态）。
- **确认按钮**：输入卡底部「确认入账」；月薪清空/非法点按 → 提示；时段倒挂 → 提示且保持展开。
- **确认后折叠**：表单收起为**一行摘要**（`¥月薪 · 上午时段 · 下午时段` + **向下箭头**），下方结果区按确认值实时跳动展示；点击摘要行（或箭头）重新展开编辑——编辑期间结果区隐藏，再次确认后更新。
- 结果计算口径不变（21.75 / 工时 / 日时秒薪 / 今日本月）。

**非目标**：改计算口径（法定工作日问题另行答复）；改首页入口；动其他页面；时间点改输入（仍轮选）。

**验收标准**：lint/type-check/build:h5/build:mp-weixin 全绿；390px 视口零横向溢出、宽屏 480 居中；进页默认值就绪但结果区不渲染；月薪可键入可轮选回填；确认后摘要行+箭头+结果区齐全；再展开→编辑→确认闭环；月薪清空与时段倒挂均拦截；`openspec validate` 通过。
